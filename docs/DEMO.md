# 10-minute demo

1. Start Postgres/MQTT.
2. Start Hardhat node.
3. Deploy contract.
4. Migrate + seed backend.
5. Start backend/frontend.
6. Log in as Blood Bank.
7. Inventory -> register a blood unit.
8. Copy the generated unit ID.
9. Verify -> enter the ID -> verify on-chain.
10. Use a delivery record and run the IoT simulator.
11. Open Deliveries -> select the delivery.
12. Watch the temperature chart update live.
13. Trigger an excursion using the simulator's random alert behavior.
14. Scan the QR using a phone/webcam.
